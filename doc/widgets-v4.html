Design board · widgets v4 · for review

One calendar package, three native looks.

A proposal for rewriting every widget in flutter_mmcalendar on top of myanmar_calendar_dart 3. Every widget renders as Material 3, Cupertino or Liquid Glass from one theme, and shows what the core already computes: holiday types, Sabbath, moon days, astrology, the Shan and Sasana years, and the chronicles. The dates below are real: October 2026, Thadingyut 1388, a big watat year. Tap a day in the calendar.

Frame
01 · Principles

What changes from 3.3.1

One scope, no per-widget theme

Wrap the app (or one screen) in MyanmarCalendarScope. It owns the client, config, language, cache and style. Widgets stop taking their own theme and config, so every widget agrees on custom holidays and time zone.

Follows the app's theme

MmCalendarThemeData is a ThemeExtension built from the app's ColorScheme. Light and dark follow automatically; nothing is hard-coded blue.

Adaptive by default

MmVisualStyle.automatic picks Cupertino on iOS and macOS, Material elsewhere, and Glass on iOS/macOS 26 and later when you opt in. Any widget can override it.

Both calendars in every cell

A day always shows its Western and Myanmar dates. Holidays are coloured by type, and Sabbath and moon days have their own marks.

State lives in a controller

MyanmarCalendarController holds the visible month and a typed selection (single, range, multi). Every callback hands back CompleteDate.

Accessible in every language

Semantics are read in the calendar's language, arrow keys move the focus, and cells grow with text size instead of clipping.

02 · Tokens and styles

The same widget in each style

These three ignore the Style switch so you can compare them side by side. Glass is drawn in Flutter: a refraction shader on Impeller, with a blur, tint and highlight fallback on web and Skia.

09 · API sketch

What using it looks like

// Once, near the top of the app.
MyanmarCalendarScope(
  language: Language.myanmar,     // or fromLocale: true
  style: MmVisualStyle.automatic, // material | cupertino | glass
  config: CalendarConfig(
    customHolidays: [familyDays],
  ),
  child: MaterialApp(
    theme: ThemeData(
      colorSchemeSeed: Colors.indigo,
      extensions: [MmCalendarThemeData.fromSeed(Colors.indigo)],
    ),
    home: const HomePage(),
  ),
);
// A month with a controller and events.
final controller = MyanmarCalendarController(
  initialMonth: DateTime(2026, 10),
  selection: const RangeSelection(),
);

MyanmarMonthCalendar(
  controller: controller,
  cellStyle: MyanmarDayCellStyle.dual,
  firstDayOfWeek: DateTime.sunday,
  eventLoader: (day) => events[day.western.date] ?? [],
  onSelectionChanged: (CalendarSelection s) { ... },
  dayBuilder: (context, MyanmarDayData day, Widget child) => child,
);
// Pickers return CompleteDate, never a raw DateTime.
final CompleteDate? day = await showMyanmarDatePicker(
  context: context,
  initialDate: DateTime(2026, 10, 18),
  inputMode: MyanmarPickerInput.myanmar, // wheels
);

final range = await showMyanmarDateRangePicker(
  context: context,
  firstDate: DateTime(2026),
  lastDate: DateTime(2027),
);
// Small pieces you can drop anywhere.
MyanmarDateText.today(pattern: '&y &M &P &ff');
MoonGlyph.forDate(day, size: 28, tilt: MoonTilt.myanmar);
HolidayList.upcoming(days: 60);
NextMoonCountdown(kinds: {MoonPhase.fullMoon});
AIPromptAction(
  date: day,
  onPrompt: (type, text) => Clipboard.setData(...),
);
10 · Decisions to confirm

Before I build

#DecisionProposalWhy
1Default week startSunday, configurable to any day3.3.1 counted from Saturday (Myanmar weekday 0). Sunday matches wall calendars sold in Myanmar.
2Default cell styledual: Western day top-left, Myanmar day bottom-rightBoth calendars at a glance, which is the reason to use this package.
3When glass turns onOpt in with MmVisualStyle.glass. automatic picks glass only on iOS/macOS 26 and laterGlass costs a backdrop pass per surface. Apps should choose it, not inherit it on old devices.
4Holiday coloursPublic red, religious saffron, cultural teal, anniversaries violet, other slate; custom holidays get an accent outline3.3.1 drew every holiday as the same red dot.
5DigitsMyanmar digits everywhere when the language is Myanmar, Shan or MonUses the core's TranslationService.digitsFor.
6Astrology descriptionsShow them, but they are English only in the core todayTranslating them belongs in myanmar_calendar_dart 3.1, not in this package.
7ChronicleCardBuild it after checking the core: getChronicleFor(1 Jan 1850) returns 263 entries, including the founding of PaganThat looks like "everything before this date", not "what was happening then". I'd like to confirm the intent in the core first.
8NamingMyanmar* for calendar widgets, Mm* for the adaptive primitivesKeeps the calendar names readable and the primitives short.
9Removed APIsDrop MyanmarCalendarTheme, OptimizedCalendarCell, PackageConstants, the performance and accessibility helpers, HoroscopeWidget and the upstream src/ re-exportsThe package isn't published as 4.0 yet, so this is the moment. One 4.0.0 changelog entry covers all of it.
10DependenciesFlutter only: no Cupertino or glass packages, one bundled shaderKeeps the package light and its look under our control.
